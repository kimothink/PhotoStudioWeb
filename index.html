PhotoStudio

여러 장의 사진을 불러오고, 필터와 프레임, 크기 조정, 메타데이터 표시를 한 화면에서 처리하는 데스크톱 사진 편집 프로그램입니다.

설치 파일 다운로드 사용법 보기

사진 정리와 보정을 빠르게 처리합니다

개별 사진 편집과 선택한 사진 일괄 처리를 같은 흐름 안에서 사용할 수 있도록 구성했습니다.

사진 불러오기

파일 또는 폴더 단위로 사진을 추가하고, 라이브러리에서 필요한 항목만 선택해 작업할 수 있습니다.

필터와 프레임

밝기, 대비, 채도와 함께 필름 느낌의 필터, 프레임 텍스트, 크기 조정 옵션을 적용할 수 있습니다.

업데이트 지원

업데이터가 함께 배포되어 새 버전이 올라오면 설치 파일을 내려받아 프로그램을 교체할 수 있습니다.

사용법

처음 실행부터 내보내기까지 자주 쓰는 순서대로 정리했습니다.

1. 로그인

  1. PhotoStudio를 실행합니다.
  2. Google 로그인 버튼을 눌러 계정 인증을 진행합니다.
  3. 계정 상태가 정상이고 만료일이 지나지 않은 경우 메인 화면으로 이동합니다.

2. 사진 추가

  1. 상단의 불러오기 버튼으로 사진 파일을 선택합니다.
  2. 여러 장을 한 번에 추가한 뒤 라이브러리 목록에서 작업할 사진을 체크합니다.
  3. 숨김 항목 표시 옵션으로 제외한 사진도 다시 확인할 수 있습니다.

3. 보정 설정

  1. 필터 목록에서 원하는 필터를 선택합니다.
  2. 밝기, 대비, 채도 슬라이더로 사진 톤을 조정합니다.
  3. 가로/세로 px와 비율 유지 옵션으로 저장 크기를 정합니다.

4. 프레임과 내보내기

  1. 프레임 텍스트를 입력하고 미리보기로 적용 상태를 확인합니다.
  2. 현재 파일 내보내기는 선택 중인 사진만 저장합니다.
  3. 체크 항목 내보내기는 선택된 사진을 같은 설정으로 일괄 저장합니다.

화면 안내

현재 캡처는 로그인 화면입니다. 로그인 후 같은 창 안에서 라이브러리, 미리보기, 필터, 내보내기 영역이 이어집니다.

로그인 영역 가운데 로그인 패널에서 Google 계정으로 인증합니다. 서버에서 사용자 상태와 만료일을 확인한 뒤 사용 가능 여부를 판단합니다.
작업 화면 로그인 후 왼쪽은 사진 라이브러리, 오른쪽은 미리보기와 편집 옵션으로 구성됩니다.
저장 방식 현재 파일만 저장하거나 체크한 사진을 한 번에 내보낼 수 있어 반복 작업을 줄일 수 있습니다.

업데이트 방식

PhotoStudio와 Updater는 함께 설치됩니다. 업데이트 확인 시 GitHub의 manifest 정보를 읽고, 현재 버전보다 높은 설치 파일이 있으면 내려받아 교체합니다.

Updater 포함 배포

Release와 Debug 빌드 모두 PhotoStudio 실행 파일과 같은 폴더에 Updater.exe가 배치됩니다.

버전 확인

manifest.json의 최신 버전, 다운로드 URL, SHA-256 값을 확인해 업데이트 파일을 검증합니다.

재실행

업데이트가 완료되면 PhotoStudio를 다시 실행해 새 버전으로 이어서 사용할 수 있습니다.
